# Hallway Flight Concept Boards

## Shared comparison contract

All three boards use the existing `app/assets/aircraft/dart-hero.webp` artwork as the aircraft reference.
The aircraft must preserve the reference Dart's white paper, sharp nose, wing planform, raised center channel, fold construction, proportions, and three-dimensional thickness.
Each board contains the same nine-background comparison set: a 1950s, 1980s, and present-day corridor rendered once in each of the three styles.
Each board also contains the same modular school-clutter inventory: trophy case, red and teal lockers, rolling CRT cart, backpack, hanging paper decorations, blank digital-sign housing, classroom door, bulletin board, cleaning cart, and floor and wall swatches.
Each board contains nine diverse student and staff archetypes, three per era.
Each archetype is shown in three recognizable states: idle, notice, and shocked sidestep or dodge.
Every board includes a larger chase-flight inset with the referenced Dart, an air-gust ribbon, school clutter, hallway depth, and a harmless surprised bystander.
No board may contain required text, logos, brands, watermarks, realistic injury, threatening impacts, weapons, outdoor sky, or identifiable real people.

## Option 1: Airmail Academy

Use case: `stylized-concept`.
Asset type: landscape visual-development asset board for a 3D paper-airplane school-hallway game.
Create a coordinated handcrafted 3D diorama with editorial screen-print influence.
Use Flight School's cream, navy, and red palette with subtle halftone, paper grain, cut-paper edges, matte painted wood, and matte painted metal.
Keep the scenes graphic but spatially believable and suitable for WebGL textures and billboard production.
Light the scenes like warm museum dioramas with clear silhouettes, adventurous energy, and child-safe visual comedy.
Organize the three corridor keyframes, modular prop kit, nine reaction triplets, texture swatches, and chase-flight inset into a clean landscape comparison board with no written labels.

## Option 2: Cinematic Schoolbook

Use case: `stylized-concept`.
Asset type: landscape visual-development asset board for a 3D paper-airplane school-hallway game.
Create premium cinematic storybook realism using dimensional hand-painted 3D illustration.
Use warm natural wood, linoleum, soft daylight, practical school lighting, restrained painterly texture, believable fabric, and expressive but non-photoreal faces.
Use warm cream, walnut, faded burgundy, and sage for the 1950s; teal, brick red, and amber for the 1980s; and pale oak, slate, and muted blue for today.
Keep the mood gently nostalgic, inviting, and witty without glossy toy surfaces or uncanny realism.
Organize the same three corridor keyframes, modular prop kit, nine reaction triplets, texture swatches, and chase-flight inset into the same clean landscape comparison board with no written labels.

## Option 3: Graphic Time Corridor

Use case: `stylized-concept`.
Asset type: landscape visual-development asset board for a 3D paper-airplane school-hallway game.
Create premium graphic 3D animation concept art with strong geometric silhouettes, bold color-blocked architecture, slightly faceted matte materials, crisp poster lighting, and expressive dimensional characters.
Use tobacco brown, oxblood, and warm cream for the 1950s; electric teal, tomato red, mustard, and fluorescent white for the 1980s; and graphite, pale concrete, vivid blue, and restrained crimson for today.
Make the architectural thresholds between eras visually dramatic while preserving one continuous school building.
Show the same referenced Dart at the same foreground scale and chase-camera angle in all three top panels.
Show exactly nine separated character triplets, for 27 full-body figures total.
Organize the same corridor keyframes, modular prop kit, reaction triplets, texture swatches, and chase-flight inset into four disciplined horizontal zones with no written labels.
